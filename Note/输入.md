# <center>输入数字

常见的几种情况：
一：***知道你要输入的每组数据有多少个***
==1、“不继续输入”为终止条件==
==2、输入的数字为0为终止条件==
==3、给定了一共有几组数据==

二：***不知道你要输入的每组数据有多少个***

---
1、“不继续输入”为终止条件，用==while(in.hasNext())== 

![](https://cdn.jsdelivr.net/gh/March030303/Picgo@main/img/20260502230349722.png)
```java
import java.util.Scanner;
public class Main {

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);

        while (in.hasNext()) {       //当有下一个数字时，就继续循环
            int n = in.nextInt();
            int sum = 0;
            for (int i = 0; i < n; i++) {
                int num = in.nextInt();
                sum += num;
            }
            System.out.println(sum);
        }
    }
}

```
2、输入的数字为0为终止条件，用==while(in.hasNextInt())+if（）== 
![](https://cdn.jsdelivr.net/gh/March030303/Picgo@main/img/20260502231114986.png)
```java
import java.util.Scanner;
public class Main {

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);

        while (in.hasNext()) {
            int n = in.nextInt();
            if (n == 0) {
                break;    //在刚才的基础上，加上if条件让他break出来
            }
            
            int sum = 0;
            for (int i = 0; i < n; i++) {
                int num = in.nextInt();
                sum += num;
            }
            System.out.println(sum);
        }
    }
}

```

3、给定了一共有几组数据，用==for循环==
![](https://cdn.jsdelivr.net/gh/March030303/Picgo@main/img/20260502231443220.png)
```java
import java.util.Scanner;
public class Main {

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int t=in.nextInt();
        for(int i = 0; i < t; i++) {
            int n = in.nextInt();
            int sum = 0;
            for (int j = 0; j < n; j++) {
                int num = in.nextInt();
                sum += num;
            }
            System.out.println(sum);
        }
    }
}

```
